

This project consists of the development of a travel planning application created using the Python programming language.
The main objective of the program is to allow a user to organize a trip by adding different countries, specifying how many days they plan to stay in each destination, and obtaining useful information such as country data and the current weather. This is possible because the application uses external APIs, which allow it to retrieve real information instead of using static data.

This project was designed using a modular structure, which means that the code is divided into different files. Each file has a specific responsibility within the program, which makes the code easier to organize 😃
